## Solari by Pinetree Research

**About Pinetree Research.** Pinetree Research is an applied AI research lab connecting agents to the world. We build the software agents run on: Solari gives them cloud browsers to reach the web, sandboxes to run code, and desktops to control a full computer, all on hardware-isolated microVMs behind one API key. Our research focuses on computer-use agents that work across the long tail of software with no usable API.
